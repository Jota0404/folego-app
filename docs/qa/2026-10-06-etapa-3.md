## Resumo para o dono

O app agora guarda os dados de verdade: entradas, contas, metas, gastos, ciclos fechados e
configurações. Os dados sobrevivem a fechar o app e voltam iguais. São 99 testes passando, e o GitHub
está verde. As três correções da Etapa 2 ficaram certas. A Etapa 3 está **aprovada com ressalvas**.

A ressalva que importa: se o arquivo de configurações um dia se corromper, o app mostraria os valores
padrão, mas fecharia ao tentar salvar uma configuração. Nenhuma tela salva configurações ainda, então
não acontece hoje. A correção é uma linha, e o desenvolvedor deve fazê-la no começo da Etapa 4.

Antes da Etapa 4, preciso de uma decisão sua (P17): quando você quiser tirar uma conta fixa, o app
deve **encerrar** a conta (ela continua descontada no ciclo em que você está) ou **excluir** (ela some
até do ciclo atual)? Recomendo encerrar, e deixar excluir só para conta cadastrada por engano.
